# Golden & Malformed APK Fixtures

Reproducible test fixtures generated by `go run scripts/generate_phase1_fixtures.go`:

- `apks/minimal_valid.apk`: Minimal pure-JVM binary AXML + DEX 035 APK (`com.example.nanoref`).
- `apks/compose_v2signed.apk` + `.idsig`: Compose + native library APK signed with APK Signature Scheme v2 X.509 ECDSA cert + v4 `.idsig` metadata + high-risk permissions (`READ_SMS`, `SYSTEM_ALERT_WINDOW`).
- `malformed_apks/zipslip_traversal.apk`: Hostile archive with `../evil_escape.txt` entry rejected by `engine/security/archive`.
- `malformed_apks/truncated_manifest.apk`: Truncated binary AXML header handled cleanly with explicit warnings.
- `expected_results/minimal_apk_expected.json`: Canonical contract expectations.
